# 检查目录

当前 `unit/` 与 `integration/` 已有实现并全量通过（`python -m pytest -q`，331 项）。默认检查不使用真实 QQ 登录态或收费 API；外部联调按用户授权的会话和操作范围执行。

| 目录 | 用途 | 现状 |
| --- | --- | --- |
| `unit/` | 不依赖真实外部服务的核心逻辑检查 | 已实现：配置、筛选、去重、会话管理、权限、事件解析、持久化迁移、记忆服务/命令/存储、DeepSeek 客户端与应答器、单实例保护、插件清单/加载/宿主/KV、工具执行服务、任务管理器、工具循环（替身模型）、ego 桥接（替身浏览器）、网页任务插件、URL 边界（含 `plugin_harness.py` 测试辅助） |
| `integration/` | 数据库及组件组合检查 | 已实现：StubOneBot 替身服务端到端（OneBot 客户端、worker 池、记忆命令、重启恢复），插件端到端（内置 hello/counter、/plugin 管理、运行状态与 KV 跨重启）、工具闭环端到端（真实插件工具 + 替身模型）、任务控制路径（会话锁外取消、非主人拒绝） |
| `contract/` | 内部类型与适配器边界的输入输出检查 | 预留 |
| `plugin_compatibility/` | 固定版本真实插件的兼容检查 | 预留（M7 AstrBot 兼容样本） |
| `fixtures/` | 合成或脱敏样本 | 预留 |
