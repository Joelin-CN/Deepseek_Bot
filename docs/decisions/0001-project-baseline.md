# 0001：独立框架与插件兼容基线

日期：2026-10-28

状态：用户已确认的项目方向；本记录不代表实现已完成。

## 决定

1. 从空仓库开发独立主程序，接受更大的开发与兼容成本。
2. 参考 AstrBot 的主流程和扩展方式，但不以 AstrBot fork 为基线。
3. 提供自己的原生插件 API，并单独实现 AstrBot 插件兼容层。
4. 记忆服务和插件系统是主要模块，不以通用存储或工具登记代替。
5. 第一条能力链路采用独立 QQ 账号、SnowLuma、DeepSeek API 和 ego-lite。
6. 在当前 Windows 电脑运行，尽量长期在线；月 API 预算为 100–300 元。
7. 当前阶段仅创建仓库目录、说明和约定，不写应用实现、不安装依赖、不接入真实账号。

## 影响

- 本项目负责会话执行、插件宿主、兼容语义与运行维护。
- 原生内核与 AstrBot 兼容类型需要保持边界。
- 兼容范围需要以版本基线和代表插件检查逐步确认。
- 人格、记忆策略和自主活动策略尚不在当前实现范围。
- 本地管理前端的范围仍待决定。

## 调整方式

用户后续改变方向时，新增决策记录或更新本记录并说明原因。无需把当前阶段约束理解成永久禁止后续实现。
